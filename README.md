# Dhaka Stocks — Market Data & Insight Project on DSEX
Visit dashboard at [Dhaka_Stocks](https://dhaka-stocks-qlabs.streamlit.app/) 

## What this is
A structured market data and analytics project on the Dhaka Stock Exchange (DSEX),
focused on clean historical data, reproducible metrics, and explainable insights.

## Capabilities
-Track and measure historical data across sectors, categories and stocks at different timelines.
-Reliably scrapes, measures and tracks Open, High, Low, Close, Volume data for each stock in the stock exchange everyday.
-Can compare across different sectors, stocks and categories across timelines.
-Can measure metrics across periods or per day.

 ## Tech Stack
- Python (scraping and ingestion)
- Supabase (database)
- Streamlit (visualization)
